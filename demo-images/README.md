# Demo images

Photos for `scripts/demo/seed.mjs`. Each harambee has its own folder. Use
**JPEG files (`.jpg`) under 5 MB**; about 1600 px wide is plenty. A missing file
is skipped with a warning, so you can add them bit by bit and re-run the seed.

Use photos you have the right to use, and don't show real people who haven't
agreed to it. For Brian (under 18), use a picture that doesn't show a child's
face, for example books and a uniform.
